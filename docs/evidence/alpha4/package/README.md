# Alpha 4 package evidence / Alpha 4 패키지 증거

This scope accepts only reviewed `PKG-001` bundles for the exact x64 Alpha Candidate ZIP. A `Pass` records the independently calculated ZIP SHA-256 and embedded commit identity, verifies that the complete physical tree containing the operator-declared unpacked `sutty.UI.exe` matches the locked ZIP by exact path, size, and SHA-256 with no extra, missing, mutated, symbolic-link, or reparse-point content, and records actual UI startup, a clean UI shutdown, and one observed `Alt+1` through `Alt+7` navigation pass with no Windows system sound. The full-tree match is not process-launch provenance. Build success, `--version`, a screenshot, or an SSH harness run cannot replace those manual UI observations.

이 범위는 정확한 x64 Alpha Candidate ZIP의 검토 완료 `PKG-001` bundle만 허용합니다. `Pass`는 독립 계산한 ZIP SHA-256과 내장 commit identity, 운영자가 관찰했다고 선언한 압축 해제 `sutty.UI.exe`를 포함한 전체 physical tree가 잠근 ZIP과 정확한 경로·크기·SHA-256까지 같고 추가·누락·변조·symbolic link·reparse point가 없음을 검증하며, 실제 UI 시작, 정상 UI 종료, `Alt+1`부터 `Alt+7`까지 한 차례 전환하면서 Windows 시스템음이 들리지 않았다는 관찰을 기록합니다. 전체 tree 일치는 process 실행 provenance가 아닙니다. 빌드 성공, `--version`, screenshot, SSH harness 실행은 이 수동 UI 관찰을 대신할 수 없습니다.

Run `Write-PackageEvidence.ps1` only after performing the UI checks against the unpacked exact Candidate and closing it, and pass the declared observed executable with `-ObservedUiPath`. Keep its parent directory pristine: it must contain exactly the ZIP tree. The script creates `redaction_reviewed: false` output outside `docs/evidence`; inspect every generated file, then use `Review-LiveEvidence.ps1 -ManualObservationReview Confirmed` to create a fresh reviewed bundle in this directory. Never edit an existing bundle or invent a result that was not observed.

정확한 Candidate를 압축 해제해 UI 검사를 수행하고 종료한 뒤에만 `Write-PackageEvidence.ps1`을 실행하고 관찰했다고 선언한 실행 파일을 `-ObservedUiPath`로 전달합니다. Parent directory에는 정확히 ZIP tree만 남아 있어야 합니다. Script는 `docs/evidence` 밖에 `redaction_reviewed: false` 출력물을 만들며, 생성 파일을 모두 확인한 다음 `Review-LiveEvidence.ps1 -ManualObservationReview Confirmed`로 이 디렉터리에 새 reviewed bundle을 만듭니다. 기존 bundle을 편집하거나 관찰하지 않은 결과를 만들지 않습니다.
