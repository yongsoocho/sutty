# Sutty v0.1.0 Alpha 5

> **Candidate only / 후보 전용:** This note does not mean that a tag or public release exists. 태그·공개 릴리스·실환경 인수 완료를 의미하지 않습니다.

Alpha 5 prepares the reviewed Windows workspace improvements for a new immutable release identity. The existing Alpha 4 tag points to an earlier commit and is not moved, deleted or reused. The latest published release remains Alpha 3 until a new promotion succeeds.

Alpha 5는 점검한 Windows 작업 공간 개선을 새로운 배포 식별자로 준비합니다. 이전 커밋을 가리키는 Alpha 4 태그는 이동·삭제·재사용하지 않습니다. 새 승격이 성공하기 전 최신 공개 릴리스는 Alpha 3입니다.

## Highlights / 주요 변경

- Preferred pane width survives responsive constraints; terminal status no longer covers cells, narrow search fits, settings/actions wrap and current settings reload on entry. / 패널 선호 너비·터미널 상태와 검색·설정 줄바꿈을 보완했습니다.
- File activation uses the clicked row, cancelled navigation cannot overwrite current state, remote actions retain the approved session/path and download selection does not create an empty destination before staging. / 파일 선택·탐색 취소·서버/경로 고정·다운로드 경로 선택을 수정했습니다.
- Command templates expand once without reinterpreting inserted values. Drafts survive refresh or rejected approval; Multi entry clears targets while retaining results. Local/external Multi input still requires separate default-off approval. / 명령 재치환·초안 유실·재진입 대상 상태를 수정하며 고급 입력 승인은 유지합니다.
- Tab removal explicitly closes WebView and rejects late callbacks, clipboard retries and pending view work, while reparenting preserves running shells. / 탭 종료 후 지연 동작을 차단하고 화면 이동 중 셸은 유지합니다.
- Shared bounded in-process gates reduce transfer-queue OS-lock contention without changing atomic replacement or cross-process exclusion. / 큐 잠금 경합을 줄이며 원자적 저장·프로세스 간 잠금은 유지합니다.
- Release metadata permits skipped unpublished Alpha tags without claiming their publication. The SSH gate binds its archive name to the checked-out source version instead of a stale hardcoded release number. / 미공개 번호를 건너뛰되 공개 상태를 과장하지 않고 SSH 검사 파일명을 소스 버전에 고정합니다.

See [UI/UX review](../UI_UX_REVIEW.md) and the proposed [small-team next steps](../SMALL_TEAM_NEXT_STEPS.md). The prior [Alpha 4 source notes](v0.1.0-alpha.4.md) describe the broader implementation history, not published Alpha 4 assets.

## Planned release assets / 계획 릴리스 자산

- `Sutty-v0.1.0-alpha.5-win-x64.zip`
- `Sutty-v0.1.0-alpha.5-win-arm64.zip`
- `SHA256SUMS.txt`
- `CANDIDATE-MANIFEST.json`
- `RELEASE-ATTESTATION.json`

Both ZIPs are unsigned self-contained evaluation packages for Windows 11 24H2 or later. Verify exact filenames and SHA-256 against the same release. ARM64 compilation/package validation does not claim ARM64 runtime acceptance.

Windows 11 24H2 이상용 코드 서명되지 않은 self-contained 시험 패키지입니다. 동일 릴리스의 정확한 파일명과 SHA-256을 확인하세요. ARM64는 빌드·패키지 검증이며 실제 실행 인수를 주장하지 않습니다.

## Release prerequisites / 출시 전제

Seal the exact candidate bytes from protected main, then accept PKG-001 and SSH-LIVE-001 against the exact x64 ZIP. Human-redaction-reviewed Pass bundles must be committed under `docs/evidence/alpha5/package/` and `docs/evidence/alpha5/ssh-auth/` before tagging the candidate source commit and promoting those same bytes. Existing Alpha 4 evidence cannot be reused for this new source/package tuple.

보호된 main에서 후보 바이트를 고정한 뒤 정확한 x64 ZIP의 PKG-001·SSH-LIVE-001을 인수합니다. 사람이 개인정보 검토를 완료한 Pass bundle을 위 Alpha 5 경로에 기록한 뒤 후보 소스에 태그를 만들고 동일 바이트를 승격합니다. 이전 Alpha 4의 증거를 새 소스·패키지에 재사용하지 않습니다.

Native DPI/keyboard/picker/clipboard/drag behavior, real SSH/SFTP/editor acceptance, broader authentication/routes/tunnels, fault/soak matrices, signing and update/rollback remain unverified. Do not use this Alpha as the sole access or recovery tool for important production systems.

Windows UI·실서버·확장 인증/경로/터널·장애/장시간·서명·업데이트/롤백 인수는 남아 있습니다. 중요한 운영 시스템의 유일한 접속·복구 도구로 사용하지 마세요.
