# Sutty v0.1.0 Alpha 3

SSH 연결 진단을 실제 UI에 노출하고, 예기치 않은 주 SSH 전송 장애의 정리 수명주기를 강화하며, Alpha ZIP 릴리스를 변경 불가능하고 자체 검증 가능하게 만든 Alpha 3입니다.

Alpha 3 exposes SSH connection diagnostics in the UI, strengthens cleanup after an unexpected primary-transport failure, and makes Alpha ZIP releases immutable and self-validating.

## 주요 변경 / Highlights

- Alpha 설치 안내를 특정 버전이나 과거 asset 이름에 의존하지 않는 안내로 변경했습니다. Alpha 3 ZIP에는 이 버전 중립 안내가 포함됩니다.
- 태그, `Directory.Build.props`, README Current 링크, 릴리스 노트, asset 이름, `BUILDINFO.txt`, ZIP inventory와 `SHA256SUMS.txt`를 함께 검증하는 release-metadata gate를 추가했습니다.
- 릴리스 workflow가 product-scope와 release-metadata fixture를 직접 실행하며, 같은 태그의 기존 GitHub Release가 있으면 실패합니다. 배포 asset은 더 이상 수정하거나 덮어쓰지 않습니다.
- 주 SSH 연결의 서버·클라이언트 식별, KEX, 검증된 호스트 키 알고리즘과 SHA-256 지문, 양방향 cipher·MAC·압축을 읽기 전용 flyout에서 확인하고 복사할 수 있습니다.
- 연결 직후 자동으로 실행하던 banner와 홈 디렉터리 탐색 명령을 제거했습니다. 연결 정보 확인만으로 `uname`, `pwd` 또는 홈 탐색 exec 요청을 보내지 않습니다.
- 예상하지 못한 주 SSH transport 오류가 발생하면 이전 협상 정보를 즉시 지우고, 소유한 terminal·SFTP·forwarding·route resource를 best-effort로 정리한 뒤 원래 오류를 보존한 `Failed` 상태로 전환합니다. 명시적 연결 종료와 오래된 client callback은 이 흐름과 경합하지 않도록 분리했습니다.
- 연결 정보 UI에 한국어·영어 레이블, 키보드 접근, 복사 상태의 live-region 알림을 추가했습니다.
- README의 self-test 목록을 기여 가이드와 맞추고, 소규모 팀용 자격증명 없는 공유 Pack이 현재 기능이 아니라 계획 단계임을 명확히 했습니다.

## 검증 / Validation

릴리스 workflow는 제품 범위와 metadata fixture, 태그·소스 버전·문서 정합성, x64·ARM64 locked restore와 Release build, 보안·Saved Host/History·터미널·설정·SFTP self-test, self-contained publish, payload 정책, ZIP의 정확한 파일 inventory와 SHA-256을 확인한 뒤 새로운 prerelease만 생성합니다.

The release workflow validates product-scope and metadata fixtures; tag, source-version, and documentation consistency; locked x64 and ARM64 restore and Release builds; security, Saved Host/history, terminal, settings, and SFTP self-tests; self-contained publishing; payload policy; exact ZIP inventories; and SHA-256 values before creating a new prerelease.

## Alpha 제한 / Alpha limitations

- Windows 11 24H2 이상만 지원합니다.
- ZIP은 코드 서명되지 않았으며 MSIX 설치 패키지가 아닙니다.
- 표시되는 정보는 주 SSH 전송의 최초 handshake snapshot입니다. SFTP는 별도 연결을 협상합니다.
- 연결 정보의 실제 지문 비교, 재연결, 무명령 연결, 간접 route와 예상하지 못한 transport 중단 인수는 승인된 실서버에서 아직 기록되지 않았습니다.
- 실제 서버의 Agent·MFA·PPK·Proxy·Jump·Forwarding 조합과 Terminal shell/TUI/IME/soak 매트릭스는 진행 중입니다.
- 16개 실서버 장시간 실행, 100GB, 100,000개 파일 매트릭스와 코드 서명·업데이트·롤백 인수는 아직 공식 완료되지 않았습니다.
- 중요한 운영 서버의 유일한 접속·복구 도구로 사용하지 마세요.

This Alpha is for personal evaluation and development/test/staging pilots. It is not a GA release or a mandatory deployment.
