# Sutty v0.1.0 Alpha 1

첫 공개 Alpha입니다. Windows에서 로컬 터미널, SSH, SFTP, 저장 명령, 최대 16개 세션의 다중 작업을 하나의 로컬 우선 작업공간으로 제공합니다.

This is the first public Alpha. It combines local terminals, SSH, SFTP, saved commands, and deliberate operations across up to 16 sessions in one local-first Windows workspace.

## 주요 기능 / Highlights

- 비밀번호, 개인키, Windows SSH Agent, 반복 OTP/MFA keyboard-interactive 인증
- Host key 저장 및 변경된 key 차단
- Direct, HTTP CONNECT, SOCKS4/5, SSH Jump, ProxyCommand 연결 경로
- Local, Remote, Dynamic port forwarding
- 지속형 SSH PTY와 Windows ConPTY, 한글 IME, ANSI/VT, 마우스, 검색 및 clipboard 지원
- 지연 로딩 SFTP tree, 파일명 검색, 재귀 업로드·다운로드, 이동·삭제·권한 변경
- retry, pause/resume, checkpoint, 앱 재실행 후 전송 복원, 크기 또는 SHA-256 검증
- 선택한 세션으로만 보내는 Multi 명령과 1→N/N→1 Multi SFTP
- 저장 Host, 접속 기록, command template, 한국어/영어, 다크/라이트 및 terminal theme
- 자격증명과 이전 명령을 기록하지 않는 선택형 Workspace·탭 복원
- Saved Host 실행 명령 `sutty.UI.exe --host <ID 또는 정확한 이름>`

## Alpha 제한 / Alpha limitations

- Windows 11 24H2 이상만 지원합니다.
- ZIP은 아직 코드 서명되지 않았으며 MSIX 설치 패키지가 아닙니다.
- 실제 서버의 전체 Agent·MFA·Proxy·Jump·Forwarding 조합 인수시험은 진행 중입니다.
- 16개 실서버 장시간 실행, 100GB, 100,000개 파일 매트릭스는 아직 공식 완료되지 않았습니다.
- 중요한 운영 서버의 유일한 접속·복구 도구로 사용하지 마세요.

This release is suitable for personal evaluation and development/test/staging pilots. It is not a GA release or a mandatory deployment.
